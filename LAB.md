# NearLink Lab
Experimental phone-to-phone WebRTC messenger. No STUN/TURN servers. Requires a functioning shared local network; does not create hotspots or use Bluetooth. Install via HTTPS and reopen before disconnecting internet. Host creates invitation, guest accepts and returns reply, host applies reply. Both compare the entire displayed fingerprint in person and confirm. Messages are memory-only. Test home Wi-Fi, isolated router, phone hotspot, SIM-disabled hotspot, and permitted airplane Wi-Fi. Manual re-pairing required after disconnection. No physical phone tests or independent security audit completed.
