# NearLink security policy
Experimental, unaudited software. Do not use for sensitive or emergency communication. WebRTC DTLS encrypts traffic; users must compare the entire certificate-derived fingerprint in person on each new session. No cloud relay, analytics, attachments, persistent chat or external runtime dependencies. Pairing expires after five minutes; incoming text is bounded and rendered as text; rate and session limits apply. Pairing codes contain local connection metadata; share only privately. Browser and hosting compromise are outside this protection. Report vulnerabilities privately using GitHub private vulnerability reporting if enabled; otherwise request a private contact without publishing exploit details.
